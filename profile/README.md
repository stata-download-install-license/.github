## Statistical Software Overview

The Stata installation is small but licence-sensitive. Editions differ in the number of variables and the size of datasets they can handle, and the platform build must match the operating system. Updates arrive as free point releases within a major version.

A typical deployment involves checking the edition against project requirements, downloading the correct installer, and entering the serial number and code during first launch. Stata features such as do-file support and user-written packages only become relevant after licensing succeeds. A Stata download from the official source avoids patched installers that break updates.

## Getting Started Playbook

Ask which edition the project requires before downloading, then pick the installer for the exact operating system version. Keep the serial number and code in a password manager rather than an email inbox. On managed machines, confirm that you have administrator rights.

Launch once as administrator, complete activation, and run the update check. Read Stata reviews about edition limits and compare Stata pricing if the dataset may grow. Keep a copy of the installer for reinstallation when a lab machine is rebuilt.

## Everyday Use

An IT administrator provisions a lab image with a network licence. A researcher reinstalls on a new laptop and reconnects to the same licence. ## Troubleshooting Common Issues

Install issues? Run the installer as administrator and confirm the platform build matches the OS.  
Performance problems? Check the working directory and ado paths if commands behave differently after a reinstall.  
License/activation? Re-enter the serial number and code exactly as issued, without trailing spaces.  
Compatibility? Install the matching point update when an old user-written package fails.  
Update failures? Use the built-in updater rather than copying binaries between machines.
